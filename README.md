# CASA SÉRICA · Landing Page Editorial

> **Objetos para habitar.**  
> Landing page editorial para CASA SÉRICA, marca de diseño y creación de objetos decorativos impresos en 3D con acabados estriados, formas orgánicas y materiales de tono mineral (arena, travertino y terracota).

---

## 🌿 Identidad del Proyecto

- **Slogan:** *«SÉRICA · Objetos para habitar»*
- **Promesa:** *«Nacemos desde la búsqueda de la calma, la atemporalidad y el valor de lo cotidiano. Curamos y creamos objetos pensados para acompañar tus días con materiales nobles, formas orgánicas y texturas que transmiten serenidad.»*
- **Origen:** Buenos Aires, Argentina.

---

## ✨ Características Técnicas y de Diseño

- **Estética Editorial Pura:** Tipografía con carácter (*Cormorant Garamond* y *Plus Jakarta Sans*), ritmo pausado y fotografía a pantalla completa.
- **Paleta de Color Auténtica:** Extraída de las fotografías reales y el logotipo oficial (verde bosque `#2D3B2F`, lino/arena `#F9F7F2` / `#F1EDE4`, piedra travertino `#DFD7CA` y acento terracota `#AB5D42`).
- **Catálogo de Piezas Reales:**
  1. *Florero Escultural en U Acanalado* — $22.000 ARS
  2. *Posavasos Minimalistas Orgánicos (Pack x4)* — $14.000 ARS
  3. *Dispensador de film y papel aluminio LENA* — $38.000 ARS
- **Venta Directa:**
  - Modal interactivo con cálculo dinámico de subtotal.
  - Generación automática de orden formateada para WhatsApp oficial de la vendedora.
- **Formulario para Encargos Especiales:** Pedidos personalizados, adaptaciones de color o proyectos de interiorismo.
- **Widget Flotante de WhatsApp:** Conexión inmediata de atención al cliente.
- **100% Responsive & Accesible.**

## 🚀 Despliegue y Visualización Local

Para previsualizar localmente:

```bash
# Con Python 3
python3 -m http.server 8080
# Luego abrir http://localhost:8080/ en tu navegador
```

También es directamente compatible con **GitHub Pages**, Vercel, Netlify o Cloudflare Pages sin necesidad de configuración adicional.
